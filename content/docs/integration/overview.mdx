Ya tienes cuenta, certificado y API Key. Ahora adapta tu sistema. Todo el trabajo técnico son estas cinco piezas, en este orden:

| # | Pieza | Qué haces | Página |
| --- | --- | --- | --- |
| 1 | Autenticación | Obtienes un token con tu email y contraseña. | [Autenticación](/docs/integration/authentication) |
| 2 | Formato JSON | Conviertes tu factura al JSON de la DGII. | [Formato JSON](/docs/integration/document-format) |
| 3 | Envío | Haces un `POST` con el JSON. Recibes el código de seguridad y el QR al instante. | [Envío de e-CF](/docs/integration/documents) |
| 4 | Consulta | Preguntas si la DGII lo aceptó o lo rechazó. | [Consulta de e-CF](/docs/integration/document-queries) |
| 5 | Anulación (opcional) | Anulas secuencias de e-NCF que no llegaste a usar. | [Anulación de e-NCF](/docs/integration/anulacion-ncf) |

¿Necesitas el JSON de un tipo concreto (31, 32, 33, 34, 41, 43…)? Está en [Ejemplos JSON por tipo](/docs/integration/formato-documentos-ecf).

<Callout title="Tú envías JSON, no XML">
  MSeller convierte el JSON a XML, lo firma con tu certificado, lo envía a la DGII y guarda el XML firmado. No necesitas generar ni firmar XML.
</Callout>

## Entornos

Cambia solo la URL base y la API Key; el resto de tu código es igual en los tres.

| Entorno | URL base | Uso |
| --- | --- | --- |
| TesteCF | `https://ecf.api.mseller.app/TesteCF` | Desarrollo y pruebas |
| CerteCF | `https://ecf.api.mseller.app/CerteCF` | Certificación con la DGII |
| eCF | `https://ecf.api.mseller.app/eCF` | Producción |

## Cómo se procesa un e-CF

El envío es **asíncrono**: respondemos en el momento con el código de seguridad y el QR, y la respuesta de la DGII llega unos segundos después. Por eso consultas el estado en un segundo paso.
