MSeller ECF es una API para emitir **comprobantes fiscales electrónicos (e-CF)** ante la DGII. Tú envías un **JSON**; nosotros lo convertimos a XML, lo firmamos con tu certificado, lo enviamos a la DGII y guardamos el XML por 10 años.

Esta guía te lleva en orden. Sigue los pasos y usa el botón **Siguiente** al final de cada página.

## Antes de empezar

Necesitas tres cosas:

- Un **certificado digital `.p12`** del negocio que va a emitir. Es obligatorio incluso para pruebas.
- Un sistema capaz de hacer **llamadas HTTP con JSON** (cualquier lenguaje sirve).
- Unos **10 minutos** para la certificación, más el tiempo de aprobación de la DGII.

## Los pasos

<Steps>
<Step>
### [Crea tu cuenta](/docs/getting-started/registration)

Regístrate en [ecf.mseller.app](https://ecf.mseller.app/register). Tu email y contraseña también son tus credenciales del API.
</Step>

<Step>
### [Sube tu certificado `.p12`](/docs/getting-started/certificado)

Lo usamos para firmar cada comprobante. Sin certificado, el API no acepta documentos, ni siquiera en pruebas.
</Step>

<Step>
### [Crea tu API Key](/docs/getting-started/api-key)

Una por entorno: **TesteCF** (pruebas), **CerteCF** (certificación) y **eCF** (producción).
</Step>

<Step>
### [Integra tu software](/docs/integration/overview)

Autentícate, arma el JSON de cada tipo de e-CF, envíalo y consulta su estado.
</Step>

<Step>
### [Certifica ante la DGII](/docs/certification/process)

Un asistente en el portal hace las pruebas por ti. Al terminar, pasas a producción.
</Step>
</Steps>

## ¿Tienes varios clientes?

Si eres una empresa de software y vas a emitir para **varios negocios**, lee primero [Varios clientes (multi-tenant)](/docs/getting-started/multi-tenant). Cada cliente tiene **su propia cuenta**, y desde tu cuenta **Proveedor** puedes crearlas y gestionar su certificado y sus API Keys.

## Preguntas que nos hacen siempre

| Pregunta | Respuesta corta |
| --- | --- |
| ¿Cuánto cuesta? | Hay un plan **Gratis** (250 comprobantes/mes, para micro y pequeñas empresas) y planes pagos por volumen. Ver [Planes y pagos](/docs/getting-started/planes). |
| ¿Cómo pago? | Con tarjeta, desde **Configuración → Facturación** en el portal. Ver [Cómo pagar](/docs/getting-started/planes#cómo-pagar). |
| ¿Hay un certificado de prueba? | No. Usa un `.p12` real, el tuyo o el de uno de tus clientes. |
| ¿Tienen webhooks? | Todavía no. El estado se consulta con el API. |
| ¿MSeller está autorizado por la DGII? | Sí. Ver la [FAQ](/docs/resources/faq#mseller-ecf-está-autorizado-por-la-dgii-como-proveedor). |

Más respuestas en [Preguntas frecuentes](/docs/resources/faq).
